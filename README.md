# 日本の送電網 論理トポロジ

**日本の基幹＋154kV 送電網の接続関係を、十社が公開している系統図 PDF から構造化したデータセット。**
各断言に**出典（どの PDF か）**・**信頼度**・**生涯管理される UUID** が付いています。

**schema v0.2**

```
ノード 1,351（active）    エッジ 1,487（active）    墓碑 46
出典   十社の公式系統図 PDF 101 份 ＋ OCCTO ＋ 沖縄電力の公表 CSV
座標   本データセットは座標を持たない（理由は「持っていないもの」を参照）
版     各社の版は揃っておらず、古いものは 2024 年度版（manifest の version_label）
```

## 位置づけ

- 日本には公開の系統実体識別体系が無い（欧州の ENTSO-E EIC 相当が存在しない）
- 公式のベクター系統 GIS も公開されていない
- 系統図は接続を漏れなく描くことを目的とした図面で、**地下線・海底線も載る**

本データセットは、その系統図から**接続関係だけ**を抽出したものです。

## データ構造

**主役は 2 つ、残り 3 つは補助**です。

```
        ┌──────────────────────────────────────────┐
        │  主テーブル                              │
        │                                          │
        │   substations ◄──from/to──  routes       │
        │   （ノード 1,359）     （エッジ 1,525）  │
        └────────┬──────────────────────┬──────────┘
                 │ uuid                 │ source_ref
        ┌────────┴────────┐             │
        ▼                 ▼             ▼
     aliases          crosswalk      sources
    （別名 1,850）    （外部 id 1,110）  （出典 13）
        補助              補助            補助
```

| | ファイル | 行数 | 1 行が表すもの |
|---|---|---:|---|
| ● | `data/substations.csv` | 1,359 | **ノード**。変電所・開閉所・変換所・発電所 |
| ● | `data/routes.csv` | 1,525 | **エッジ**。2 つのノードを結ぶ送電線区間 |
| | `data/aliases.csv` | 1,850 | ノードの別名（旧称・略号・実名・図上番号） |
| | `data/crosswalk.csv` | 1,110 | 外部データセットの id への対応（**座標を引く唯一の経路**） |
| | `data/sources.csv` | 13 | 出典（どの PDF / CSV から来たか） |
| | `sources/manifest.csv` | 104 | 取得 manifest（URL・取得日・版表記）。`data/` の外 |

**この 2 つだけで系統グラフになります**：`routes` の `from_substation` / `to_substation` が
`substations.uuid` を指す、それだけです。

- **UTF-8 / LF / ヘッダあり**
- **主キーはすべて UUID v4。生涯不変・再利用しない**
- **削除しない。** 廃止・誤りは `status` を変えて残す（墓碑化）
- **必ず `status = 'active'` で絞ること**（墓碑が混ざります）

## 何がわかっていて、何がわかっていないか

### ✅ 持っているもの

| | 状態 |
|---|---|
| **接続関係** | 1,487 辺。**全てに `source_ref`（どの PDF か）と `confidence` が付く** |
| **電圧** | 辺の 99.5%。**系統図の線幅実測から判定**（凡例ではなく図内の既知骨幹で裏取り） |
| **事業者** | 100%。系統図の発行元そのものなので確度が高い |
| **站名** | 図の表記そのまま。匿名区の実名は `aliases` に別途 |
| **同期系統** | 100% |
| **時間軸** | 廃止・誤りは削除せず墓碑化 |

### ⛔ 持っていないもの

| | なぜ |
|---|---|
| **座標** | **全行が空。** 本データセットに書いてよい座標は外部データセットの実測に突合できた値だけですが、その実測値自体は ODbL なので持ち込めません。→ **`crosswalk` の id 経由で引いてください**（677 站 = 50.1%） |
| **インピーダンス R/X/B** | 日本では保安上非公開（託送供給等約款の範囲外）。公開データからは得られない |
| **変圧器諸元・容量・母線への負荷配分** | 同上 |
| **66kV 以下の配電系統** | 対象外（基幹＋154kV のみ） |

**→ そのまま潮流計算はできません。** 電気的パラメータは別途調達が必要です。

## 限界

### 人手による review を経ていない

- 抽出・追加・訂正はすべて機械 / agent によるもの
- **誤り率は未測定**

他ソースとの分岐は「どちらかが誤っている」ことを示すだけで、
どちらが誤りかは原図に当たるまで決まりません。

### 座標が引ける範囲

| 層 | 全辺 | 両端とも座標あり | 率 |
|---|---:|---:|---:|
| 骨幹（500/275/220/187/DC/FC） | 623 | **402** | **64.5%** |
| 154kV 以下 | 864 | 418 | 48.4% |
| 計 | 1,487 | **820** | **55.1%** |

**座標が付くと連結性は落ちます。** 全体の骨幹は最大連結成分が 89%（437/493 站）でほぼ一枚の網ですが、
**座標サブグラフの骨幹では 59%（187/318 站）に割れます**。座標の欠けが幹線の途中に開くためです。
→ **座標付きで区間級の解析（潮流・N-1）ができる上限はこの 59%。**

**region 別の座標カバー率**：

| region | 站 | 座標 | 率 |
|---|---:|---:|---:|
| hokkaido | 45 | 36 | 80% |
| kyushu | 86 | 67 | 78% |
| chugoku | 38 | 27 | 71% |
| shikoku | 33 | 21 | 64% |
| chubu | 154 | 96 | 62% |
| tokyo | 406 | 221 | 54% |
| hokuriku | 48 | 23 | 48% |
| okinawa | 94 | 45 | 48% |
| tohoku | 297 | 104 | 35% |
| **kansai** | 150 | 37 | **25%** |

**関西だけが桁違いに低い**のは、原図が全站匿名で名前による突合が原理的にできないためです。
**関西は座標付きの系統解析には現状使えません。**

### 匿名区

関西 150 站・中国 38 站・沖縄 85 站が**図上で符号のみ**です（`A`・`基S1`・`27`）。
実名化の進捗は **沖縄 96% / 中国 53% / 関西 31%**。実名は `aliases` にあります。

### 座標が無い 674 站の内訳

| 分類 | 件数 | 性質 |
|---|---:|---|
| 実名 | 224 | 下記で細分 |
| **発電所** | 215 | **缺口ではない**（下記） |
| 匿名コード | 125 | 関西・中国。図に名前が無い |
| **占位記号** | 70 | **変電所ですらない**（下記） |
| 沖縄の数字略号 | 40 | 実名は判明済み。外部側に対応が無いだけ |

**実名 224 件の細分**：通常の変電所名 **131** ／ `kind=other`（母線・分岐点で**そもそも站ではない**）42 ／
発電所併設名 24 ／ 開閉所 17 ／ 変換所・FC 6 ／ 局配 4。

**「座標が無い 674」のうち、埋めるべき缺口は 674 − 215 − 70 − 42 = 347 件です。**

**発電所 215 件が缺口でない理由**：上流が名前を持たせていません。
TEPCO の匿名化 ID 108 件（`発電所1123016`）／東北のシミュレーション用白枠 75 件（実体設備でない）／
図内の局部番号 32 件。**207/215 が番号のみ**で、名前による突合が原理的に成立しません。
TEPCO は「実際の需要家又は発電所数等とは異なる場合があります」と公式に明記しています。

**占位記号 70 件が缺口でない理由**：東北の `__X` / `__P` は凡例
「発電所（シミュレーション精度向上のための情報提供あり）」の白枠で、**変電所ではありません**。
この事実は `substations.csv` の `notes` に書かれています。

### 埋まらないと分かっている部分

通常の変電所名 131 件について、隣接站の座標から位置を絞って外部データセットと突合した結果：

| | 件数 | 実態 |
|---|---:|---|
| 圏内に未使用の候補あり | 61 | 位置は合うが名前が合わない |
| 隣接アンカー無し | 41 | 隣も座標を持たない連鎖 |
| **圏内に候補ゼロ** | **33** | **外部側に本当に存在しない** |

**圏内ゼロの 33 件はほぼ全て東京都心・横浜の地下変電所**
（角筈=新宿・常盤橋=大手町・北渋谷・南新橋=汐留・関内・横浜根岸・生麦…）。
共通点は **22kV 母線を持つこと**——東京都心特有の配電電圧です。
地下設備は地図データのカバレッジが極めて薄いため、**この経路では埋まりません。**

### 粒度（外部データと比べるとき）

- **1 レコード ＝ 1 区間。** 長距離幹線は途中の站で複数レコードに分かれます
- 外部データと**本数を直接比較しないでください**（相手の 1 本＝こちらの複数区間のことがあります）
- **並行回線は 1 辺に併合**しています（回線数は `n_circuits`。ただし充填 13%）

### その他

- **孤立站 245 件。うち実名は 28 件。** 残りは発電所・匿名符号で、多くは異常ではありません
- **電圧整合の未解決 4 站**：`voltage_max_kv` が接続線の電圧を下回る站（`AA`・`AB`・`BM`・`内房`）
- `voltage_max_kv` が空の站が 9.3%（主に発電所と占位記号）。辺の `voltage_kv` は 99.5% 埋まっています

## 使い方

```sql
-- 系統グラフ（これだけで足ります）
SELECT r.uuid, r.name_official, r.voltage_kv,
       sf.name_official AS from_name, st.name_official AS to_name
FROM routes r
JOIN substations sf ON sf.uuid = r.from_substation AND sf.status = 'active'
JOIN substations st ON st.uuid = r.to_substation   AND st.status = 'active'
WHERE r.status = 'active';

-- 匿名区も実名で引く
SELECT s.uuid, s.name_official AS code, a.alias AS real_name
FROM substations s
JOIN aliases a ON a.uuid = s.uuid
WHERE s.status = 'active' AND a.alias LIKE '%変電所';

-- 座標が要るとき（本データセットは座標を持たないので外部 id を取り出す）
SELECT s.uuid, s.name_official, c.target_system, c.target_id, c.match_method
FROM substations s
JOIN crosswalk c ON c.uuid = s.uuid
WHERE s.status = 'active'
  AND c.match_method NOT IN ('name_t3_region','name_t3_national','affine');  -- 弱い手法を除外
```

## 列挙値の定義

### `confidence`（全テーブル共通・**最重要**）

| 値 | 意味 | 辺での実測（active 1,487） |
|---|---|---:|
| `verified` | **人手で原図に当たった記録があるもの** | 50 |
| `extracted` | 原図から機械 or agent が読んだが、人手照合はしていない | 1,364 |
| `inferred` | 推定（名寄せの緩和一致・拓撲・アフィン等） | 73 |

### `region`

`hokkaido` `tohoku` `tokyo` `chubu` `hokuriku` `kansai` `chugoku` `shikoku` `kyushu` `okinawa`
＋ `routes` のみ `inter`（跨社連系線）

### `sync_area`（同期系統）

| 値 | 意味 |
|---|---|
| `east50` | 東日本 50Hz（北海道を除く） |
| `west60` | 西日本 60Hz |
| `hokkaido` | 北海道（本州とは HVDC でのみ接続） |
| `okinawa` | 沖縄（独立系統） |

**`link_class != inter_area` の辺は `sync_area` を跨ぎません**（データ側で保証）。

### `link_class`

| 値 | 意味 |
|---|---|
| `intra` | 同一エリア内 |
| `inter_ac` | 交流の跨社連系線（同一同期系統内） |
| `inter_area` | **同期系統をまたぐ**（HVDC / 周波数変換所 / BTB） |

### `tier`

電圧階級のグループ。`tier1` ≈ 500kV 系、`tier2` ≈ 275/220/187/66kV 系、`tier3` ≈ 154kV 系。
**厳密な電圧の同義語ではありません**（各社の階級構成が違うため）。電圧で絞るなら `voltage_kv` を使ってください。

### `crosswalk.match_method`

| 値 | 件数 | 意味 |
|---|---:|---|
| `name_t1_region` | 495 | 厳格な正規化 + 同一 region の名前一致 |
| `name_osm_upstream` | 447 | 外部データセット上流への直接照会で名前一致 |
| `name_t1_national` | 32 | 名前が全国唯一なので跨 region を許した一致 |
| `deanon` / `deanon_geo` | 32 | 匿名区の同定（アフィン推算 + 突合） |
| `abbrev_table+ajg_name` | 25 | 沖縄の官略号対照表 + 相手側の名前の一致 |
| `name_t3_region` / `_national` | 23 | 接辞を落とした緩い一致（**弱い**） |
| `combined` | 17 | 複数手法の組み合わせ |
| `abbrev_table+affine` | 14 | 官略号対照表 + アフィン位置 |
